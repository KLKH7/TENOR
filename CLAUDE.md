# Concentrate — conventions for agents working in this repo

Concentrate is a research prototype: a structured, time-aware, source-cited, entity-linked
memory built over Granola meeting notes, plus a benchmark comparing it to "agent + top-k
transcript retrieval". The audience is Granola's engineering team: rigour and honesty beat polish.

## Non-negotiables
- **Fidelity to Granola.** Model the real public API/MCP. Every field we rely on is tagged
  `VERIFIED` or `ASSUMED` in `docs/SCHEMA_NOTES.md`. Never silently invent API behaviour; if you
  must assume, add a row there first.
- **Source boundary.** All Granola I/O lives in `concentrate.sources` behind the `Source` protocol
  (`GranolaAPISource` for the REST API, `GranolaMCPSource` for the official MCP, `FixtureSource`).
  The MCP source is read-only by construction: never call MCP write tools. Downstream code never imports httpx or knows which source
  it is reading. Fixtures use the exact API response shape and are validated by the same Pydantic
  models (`tests/test_contract.py`).
- **Transcripts are channel-attributed.** `speaker.source: "microphone"` = "Me" (note owner),
  `speaker.source: "speaker"` (system audio) = "Them". `attribution` (me|them), `diarization_label`
  and `name` are optional and usually absent. No audio, no word-level confidence. Don't model
  what Granola doesn't give us.
- **Secrets only from env** (`GRANOLA_API_KEY`, `ANTHROPIC_API_KEY`). Never log, print, repr or
  persist them. `.env.example` lists every variable.
- **Honest evals.** Dev/test split of questions; never tune on test. Bad results get reported in
  `docs/DESIGN.md` and the README, not hidden. Every eval result records git SHA, model, prompt
  versions, seed, date.
- **Budget.** Before any eval run estimated > $2 of LLM spend, print the estimate and ask the user.

## Code
- Python 3.11, `uv`. Run: `uv run pytest`, `uv run ruff check .`, `uv run ruff format .`,
  `uv run mypy` (strict on core/sources/cli; extend `[tool.mypy].files` as packages mature).
- Package layout: `packages/concentrate/<module>` → `import concentrate.<module>`.
- Small typed modules, docstrings on public functions, no dead code. Pydantic v2 for all
  data crossing a boundary.
- Determinism: every generator/eval takes `--seed`; same seed → byte-identical output.
  Inject clocks/RNGs; never call `time.time()`/`random` at module scope in logic under test.
- LLM calls go only through `concentrate.llm` (structured output, retries, disk cache keyed by
  model+prompt hash, token/cost accounting per call and per stage). Prompts live in `prompts/`
  as versioned files (`<name>.v<N>.md`); the version is logged with every result.
- Tests: no network. Mock HTTP with `httpx.MockTransport`; use fake clocks for time.

## Data
- `data/fixtures/northwind` is generated by `concentrate synth --seed 42` and must match it exactly (a test enforces this). Never hand-edit it: change the generator and regenerate.
- Questions have a dev/test split. Look only at dev when tuning anything.

## UI (Phase 6)
- Replicate layouts and interactions from the Mobbin references in `docs/UI_REFERENCES.md` (Granola's own screens first). Use the Mobbin connector for any new view: search before designing. Match Granola's visual language closely (the user asked for this); never use Granola's logo, name, wordmark or fonts, and don't commit Mobbin screenshots (link to `mobbin_url` instead).

## Workflow
- Work proceeds in phases (see README "Roadmap"). After each phase: tests green, update
  `docs/DESIGN.md` (decisions + trade-offs), summarise built / assumed / open questions, stop for
  review.
